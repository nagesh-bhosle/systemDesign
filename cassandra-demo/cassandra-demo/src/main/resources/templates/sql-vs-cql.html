SQL vs CQL

CQL looks like SQL but the similarities end at the syntax. There are no joins, no arbitrary WHERE clauses, and no aggregates over the whole table - everything follows from the partition key.

Side by side

FeatureSQLCQL
JoinsSupportedNot supported
WHEREAny columnPartition key (+ clustering)
ORDER BYQuery-timeSchema-time (clustering)
SchemaNormalizedDenormalized per query
Scale-outVertical firstHorizontal by design
